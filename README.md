# 💬 AI Sentiment Analyzer

Analyzes customer reviews as Positive or Negative using 
DistilBERT — a state-of-the-art NLP model.

## 🚀 Live Demo
👉 https://sentiment-analyzer-hfajgizfyrbsupxokbcdri.streamlit.app/

## ✨ Features
- Single review analysis with confidence score
- Bulk CSV upload and analysis
- Visual sentiment breakdown charts
- Download results as CSV

## 🛠️ Tech Stack
- HuggingFace Transformers (DistilBERT)
- PyTorch, Streamlit, Plotly, Pandas
